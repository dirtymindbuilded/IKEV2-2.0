# IKEv2 Manager

اپ اندروید (۱۳+) برای مدیریت لیست بزرگ سرورهای IKEv2/IPsec: اسکن سریع شبکه (مرحله ۱)، تست واقعی تونل VPN (مرحله ۲)، رتبه‌بندی و اتصال به بهترین سرور. بدون بک‌اند، بدون آنالیتیکس.

## ساخت APK بدون Android Studio
1. یک repo خالی در GitHub بسازید و محتوای این پوشه را در شاخه `main` پوش کنید.
2. تب **Actions** ← workflow به نام **Build APK** (خودکار اجرا می‌شود؛ یا Run workflow).
3. بعد از پایان، از صفحه‌ی همان run در بخش **Artifacts** فایل `IKEv2Manager-debug-apk` را دانلود و `app-debug.apk` را نصب کنید.

Workflow: JDK 17، نصب SDK 35، Gradle 8.9 (لازمه‌ی AGP 8.7.3)، کامپایل Kotlin، تست‌های واحد، ساخت APK. گزارش تست‌ها هم آپلود می‌شود. Gradle wrapper در repo نیست؛ workflow خودش Gradle را نصب می‌کند.

## استفاده
1. **Servers**: افزودن دستی / Paste / Import فایل TXT یا CSV (`hostname[,label]`).
2. **Credentials**: یک بار username/password (EAP-MSCHAPv2) را وارد کنید؛ رمزنگاری‌شده با Android Keystore ذخیره می‌شود.
3. **Dashboard ← Quick scan**: مرحله ۱ (DNS، ICMP، UDP 500/4500، TCP 443). فقط راهنمای اولیه است، نه اثبات کارکرد IKEv2.
4. **VPN test**: مرحله ۲ (All / Top 5/10/20 / Selected). یکی‌یکی وصل می‌شود، تونل را می‌سنجد و قطع می‌کند. دفعه‌ی اول اندروید خودش پنجره‌ی اجازه‌ی VPN را نشان می‌دهد.
5. رتبه‌بندی، جزئیات و تاریخچه در Servers؛ خروجی CSV/TXT از Settings (هرگز شامل رمز نیست).

## محدودیت‌ها (صادقانه)
- **این کد در محیط توسعه کامپایل و روی دستگاه تست نشده است.** تست‌های واحد منطق (parser، آمار، رتبه‌بندی، ماشین حالت، رمزنگاری با cipher جعلی، Stage2 با موتور جعلی) نوشته شده‌اند ولی اولین اجرای واقعی‌شان روی GitHub Actions است. اگر build خطا داد، لاگ را بفرستید تا درست شود.
- **اتصال واقعی VPN تست نشده.** باید روی دستگاه واقعی با یک سرور EAP-MSCHAPv2 امتحان شود (docs/ARCHITECTURE.md ← Unverified assumptions).
- API پلتفرم اندروید فقط EAP-MSCHAPv2/سرتیفیکیت سیستمی را می‌پذیرد؛ PSK، گواهی کلاینت و الگوریتم‌های قدیمی (3DES, MODP1024) پشتیبانی نمی‌شوند. اندروید «رمز غلط» و «گواهی/هویت غلط» را از هم جدا گزارش نمی‌کند.
- تست مرحله ۲ فقط وقتی اپ باز است اجرا می‌شود (صفحه روشن می‌ماند)؛ foreground service اضافه نشده.
- strongSwan: تعبیه نشده (GPLv2). فقط ارسال پروفایل `.sswan` (بدون رمز) به اپ رسمی strongSwan؛ تست نشده و بدون پایش وضعیت.
- ایکون اپ و release signing تنظیم نشده (فقط debug APK).
